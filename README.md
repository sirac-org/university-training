# التدريب الجامعي — منصة النتائج والأداء

موقع ثابت (HTML/CSS/JS) يعرض نتائج الدورات التدريبية لجمعية سراج: الإحصائيات، الدورات، المحاضرون، والمراكز.
يدعم العربية والتركية والإنجليزية، والوضع الفاتح والداكن، ويعمل بالكامل بدون خادم.

## الصفحات
- `index.html` — الرئيسية
- `stats.html` — الإحصائيات
- `courses.html` — الدورات
- `lecturers.html` — المحاضرون
- `centers.html` — المراكز

## تعديل البيانات
كل الأرقام والأسماء والترجمات في `assets/data.js` — عدّلها وتنعكس على كل الصفحات.
